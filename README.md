# Dinitha Ranketh | Developer Portfolio

A responsive, single-page developer portfolio designed to showcase my journey, technical competencies, and practical software engineering experience as an aspiring Full-Stack Engineer. Built with a focus on modern web performance, reusable component architecture, and a clean, tech-forward aesthetic.

## 🛠️ Built With

* **React.js:** Handles the core component-based UI architecture, state management, and seamless single-page routing.
* **Tailwind CSS:** Drives the utility-first styling for rapid, responsive grid layouts, fluid typography clamps, and structural spacing.
* **Custom CSS (`@layer components`):** Manages advanced UI refinements, including custom gradient clipping, sub-pixel border precision, backdrop blur effects, and complex hover state animations.

## 📂 Portfolio Sections

* **Educational Background:** Details my current undergraduate computer science studies, core module focus areas, and academic timeline.
* **Technical Skills:** A deeply categorized breakdown of my active tech stack, spanning frontend interfaces, backend architecture, core programming languages, databases, and workflow utilities.
* **Academic Projects:** Collaborative university builds and coursework modules focused on practical system design and core software principles.
* **Personal Projects:** Independent, hands-on full-stack applications and engineering experiments that demonstrate applied, logic-first problem-solving.
